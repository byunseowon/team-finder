# Team Finder - Unreal 7기 팀 빌딩 웹앱

Unreal Engine 부트캠프 7기 수강생들의 팀 빌딩을 위한 웹 애플리케이션입니다.
수강생들이 서로의 프로필을 탐색하고, 자유롭게 팀을 구성할 수 있습니다.

## 주요 기능

- **프로필 관리**: 역량, 선호 장르, 좋아하는 게임, 게임 컨셉, 협업 스타일 등록, 개인 비밀번호 변경
- **인원 탐색**: 이름/장르 기반 검색 및 필터, 카드 클릭 시 상세 모달, 관심 표시
- **구인구직 보드**: 팀원 모집(구인) 및 팀 탐색(구직) 게시판, 작성/수정/삭제
- **팀 관리**: 자유 팀 생성, 팀장의 팀원 추가, 1인 1팀 제한
- **팀 승인 퍼널**: 팀빌딩 중 → 승인 신청(최소 인원 충족 시) → 관리자 승인. 승인 후 팀 수정 불가
- **팀 현황**: 전체 팀 구성 현황 대시보드, 상태별 필터(팀빌딩 중/승인 신청/승인 완료)
- **단계별 접근 제어**: 프로필 작성 단계 → 팀 빌딩 시작 → 잠금
- **관리자**: 수강생 명단 관리(직접 입력/엑셀 업로드), 공통 비밀번호, 팀 인원 설정, 팀 승인/취소, 잠금 기능

## 운영 단계

| **단계** | **수강생 권한** |
|---|---|
| 1단계 (기본) | 프로필 작성 + 팀 현황 조회 |
| 2단계 (팀 빌딩 시작) | 전체 기능 사용 가능 |
| 3단계 (잠금) | 팀 현황 조회만 가능 |

## 팀 승인 퍼널

```
팀빌딩 중 → (최소 인원 충족 시 팀장이 신청) → 승인 신청 → (관리자 승인) → 승인 완료
```

- 승인 신청 후 팀 구성 변경 불가
- 승인 완료된 팀원은 다른 팀으로 이동 불가
- 관리자가 승인 취소 가능 (팀빌딩 중으로 복귀)

## 기술 스택

- **Frontend**: Next.js (App Router, TypeScript, Tailwind CSS)
- **Database**: Supabase (PostgreSQL)
- **Hosting**: Vercel

## 실행 방법

```bash
npm install
npm run dev
```

`.env.local` 파일에 Supabase 환경 변수 설정이 필요합니다.

```
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```
